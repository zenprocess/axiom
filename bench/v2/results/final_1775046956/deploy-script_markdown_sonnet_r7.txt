The user needs to approve the write. The script is ready — here's a summary of what it does:

**`deploy.sh`** — full pipeline with rollback:

| Step | What happens |
|------|-------------|
| `build` | `docker build` with OCI labels (version, git SHA, timestamp); tags `vX.Y.Z` + `latest` |
| `push` | Pushes both tags to the registry |
| `git tag` | Creates an annotated tag from `pyproject.toml` version, pushes to origin |
| `deploy` | Stops old container, starts new one via SSH (or locally); runs a 30 s health check loop and **auto-rolls back** if it fails |
| `cleanup` | Prunes local images beyond the last N versions (default: 3) |

**Rollback:**
```bash
ROLLBACK_TAG=v0.5.0 ./deploy.sh rollback
```

**Key env vars to set:**
```bash
REGISTRY=ghcr.io/yourorg   # default: ghcr.io/zenprocess
DEPLOY_HOST=user@prod.host  # omit for local-only deploy
DEPLOY_DIR=/srv/axiom
```

**Subcommands:**
```
./deploy.sh          # full pipeline (default)
./deploy.sh build    # build only
./deploy.sh push     # push only (reads version from pyproject.toml)
./deploy.sh rollback # rollback (requires ROLLBACK_TAG=)
./deploy.sh help
```
