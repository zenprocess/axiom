**Key design decisions:**

- **`UserClient.fetch_user`** is `async` — all I/O goes through `httpx.AsyncClient` per the `async-io` rule
- **`User` / `Address`** are Pydantic `BaseModel` subclasses with `model_validate()` for safe deserialization
- **Typed exceptions** (`UserNotFoundError`, `UserAPIError`) let callers handle 404 vs other failures distinctly
- **`structlog`** throughout — no `print()` or `logging` imports
- **`API_BASE_URL` env var** overrides the default base URL so secrets/configs stay out of code
- Error handling covers: timeout, network failure, 404, and unexpected status codes
