**`test_framework.py`** — ~230 lines, no external deps beyond `pydantic`

**Architecture:**

| Component | Mechanism |
|---|---|
| **Registration** | `@test` / `@fixture` decorators populate module-level registries |
| **Fixtures** | Generator fixtures support setup/teardown via `yield`; resolved by param name |
| **Assertions** | Standalone functions raising `AssertionFailure`; `assert_raises()` is a context manager |
| **Runner** | `run_suite()` is `async`, supports both sync and async test functions |
| **Discovery** | `discover(path)` globs `test_*.py` recursively, imports via `importlib` |
| **Results** | `TestResult` / `SuiteResult` are Pydantic models |
| **Output** | `print_results()` with ANSI color codes |

**Usage example:**

```python
from test_framework import fixture, test, assert_equal, assert_raises, run_suite, print_results
import asyncio

@fixture
def sample_list():
    data = [1, 2, 3]
    yield data          # setup
    data.clear()        # teardown

@test
def test_addition():
    assert_equal(1 + 1, 2)

@test
def test_list_length(sample_list):   # fixture injected by name
    assert_equal(len(sample_list), 3)

@test
async def test_async_op():
    result = await asyncio.sleep(0)
    assert_equal(result, None)

@test
def test_raises():
    with assert_raises(ZeroDivisionError):
        1 / 0

if __name__ == "__main__":
    suite = asyncio.run(run_suite())
    print_results(suite)
```
