## `test_framework.py`

The file has four sections: **models**, **assertions**, **fixtures/skip**, and the **runner + discovery**.

### Key design decisions

| Concern | Approach |
|---|---|
| Data structures | `TestResult` / `SuiteResult` are Pydantic `BaseModel`s |
| Async | Runner uses `async def`; both sync and `async def` tests work |
| Fixtures | `@fixture` decorator registers by name; injected via parameter inspection |
| Skip | `@skip("reason")` decorator |
| Discovery | `importlib` loads `test_*.py` / `*_test.py` files recursively |
| Output | `print()` as requested (runner output only) |

### Assertions provided

```
assert_equal         assert_not_equal
assert_true          assert_false
assert_in            assert_not_in
assert_is_none       assert_is_not_none
assert_raises        assert_almost_equal
```

### Usage

```python
# Define fixtures
@fixture
def db() -> dict:
    return {"users": []}

# Write tests (fixtures injected by parameter name)
async def test_insert(db: dict) -> None:
    db["users"].append("alice")
    assert_equal(len(db["users"]), 1)

@skip("not implemented yet")
def test_delete(db: dict) -> None:
    ...

# Run manually
asyncio.run(run_suite([test_insert, test_delete], suite_name="db tests"))

# Or via CLI:
#   python test_framework.py .          # discover all test_*.py
#   python test_framework.py -v         # verbose tracebacks
```
