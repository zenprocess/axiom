**`testkit/framework.py`** — ~250 lines, no dependencies beyond stdlib:

**Features:**

| Feature | How |
|---|---|
| Assertions | `assert_equal`, `assert_true`, `assert_raises`, `assert_in`, etc. |
| Fixtures | `@fixture` decorator; generator fixtures support teardown via `yield` |
| Test registration | `@test` decorator, or auto-discovery of `test_*.py` files |
| Skip | `@skip("reason")` decorator |
| Async tests | `async def test_*` works natively |
| Runner | `run_suite()` + `print_results()` with color output |
| Discovery | `discover(path)` — walks `test_*.py`, collects `test_*` functions |
| Exit code | `1` on failures/errors, `0` on all pass |

**Usage example:**

```python
from testkit.framework import fixture, test, skip, assert_equal, assert_raises

@fixture
def sample_data():
    data = {"key": "value"}
    yield data          # teardown runs after the test
    data.clear()

@test
def test_lookup(sample_data):
    assert_equal(sample_data["key"], "value")

@skip("not implemented yet")
def test_future_feature():
    ...

# Run: python -m testkit.framework ./tests
```
