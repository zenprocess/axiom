Here's the complete framework — a single file `testframework.py`:

**Assertions** — `assert_equal`, `assert_not_equal`, `assert_true`, `assert_false`, `assert_is_none`, `assert_is_not_none`, `assert_in`, `assert_raises`

**Fixtures** — `@fixture` decorator registers a function by name; test parameters are auto-resolved from the registry

**Test registration** — `@test` decorator marks functions as test cases

**Discovery** — `discover()` recursively finds `test_*.py` / `*_test.py` files, imports them, and collects both `@test`-decorated and `test_`-prefixed functions

**Runner** — `run()` executes tests, resolves fixtures, times each test, and prints PASS/FAIL with a summary

Example usage:

```python
from testframework import test, fixture, assert_equal, assert_raises, run

@fixture
def sample_list():
    return [1, 2, 3]

@test
def test_length(sample_list):
    assert_equal(len(sample_list), 3)

@test
def test_contains(sample_list):
    assert_equal(sample_list[0], 1)

@test
def test_division_by_zero():
    assert_raises(ZeroDivisionError, lambda: 1 / 0)

if __name__ == "__main__":
    run()
```
