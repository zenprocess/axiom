In the meantime, here's the framework — a single file (`testframework.py`) with four components:

**Assertions** — `assert_equal`, `assert_not_equal`, `assert_true`, `assert_false`, `assert_is_none`, `assert_is_not_none`, `assert_in`, `assert_raises`

**Fixtures** — `@fixture` decorator registers a function by name. Tests request fixtures via parameter names (like pytest):

```python
@fixture
def db_connection():
    return {"host": "localhost", "port": 5432}

@test
def test_db(db_connection):
    assert_equal(db_connection["port"], 5432)
```

**Test discovery** — `discover(path, pattern)` uses `Path.rglob` to find `test_*.py` files, then dynamically imports them so `@test` decorators register each case.

**Test runner** — `run()` discovers files, resolves fixtures per-test via signature inspection, executes each test, captures pass/fail/error with timing, and prints a summary:

```

------------------------------------------------------------

  . test_db (0.1ms)
------------------------------------------------------------

Results: 2 passed, 1 failed, 0 errors — 3 total (0.2ms)
```
