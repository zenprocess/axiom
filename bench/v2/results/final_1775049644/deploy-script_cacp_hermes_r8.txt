Here's a production-ready bash deployment script that complies with all your coding standards (no `print()`, no secrets, proper error handling, etc.). Since bash itself doesn't use Pydantic or `structlog`, those constraints apply to any embedded Python code—but this script avoids Python entirely.

Key features:
- Uses `set -euo pipefail` for strict error handling
- Validates required environment variables (no hardcoded secrets)
- Implements rollback via Docker image tag retention and Kubernetes `kubectl rollout undo`
- Uses `trap` for cleanup
- Avoids `--force` pushes (uses `git push origin tag`)
- All I/O (e.g., `docker`, `kubectl`) wrapped in `try`-like constructs via `||` with fallbacks

```bash
#!/bin/bash
set -euo pipefail

# === Configuration === #
# Required environment variables (must be set externally, e.g., CI secrets)
: "${DOCKER_REGISTRY:?Error: DOCKER_REGISTRY is not set}"
: "${IMAGE_NAME:?Error: IMAGE_NAME is not set}"
: "${GIT_TAG:?Error: GIT_TAG is not set}"
: "${K8S_DEPLOYMENT:?Error: K8S_DEPLOYMENT is not set}"
: "${K8S_NAMESPACE:?Error: K8S_NAMESPACE is not set}"

# Optional: fallback to current commit SHA if not provided
GIT_TAG="${GIT_TAG:-$(git rev-parse --short HEAD)}"

# === Helpers === #
log() {
  # Uses /dev/stdout for logging (structlog-style but bash-native)
  echo "[$(date -Iseconds)] $*" >&2
}

cleanup() {
  local exit_code=$?
  if [[ $exit_code -ne 0 ]]; then
    log "Deployment failed. Attempting rollback..."
    rollback
  fi
}

rollback() {
  # Rollback: 1) Reset git tag to previous commit (if tag was updated)
  #           2) Re-deploy previous Docker image via kubectl
  log "Rolling back Docker image to previous tag: ${PREV_DOCKER_IMAGE:-}"
  if [[ -n "${PREV_DOCKER_IMAGE:-}" ]]; then
    docker pull "${PREV_DOCKER_IMAGE}" || true
    kubectl set image "deployment/${K8S_DEPLOYMENT}" \
      "${K8S_DEPLOYMENT}=${PREV_DOCKER_IMAGE}" \
      -n "${K8S_NAMESPACE}" || true
  fi

  # Git tag rollback (only if tag existed before)
  if [[ -n "${PREV_COMMIT:-}" ]]; then
    git tag -d "${GIT_TAG}" || true
    git push origin ":refs/tags/${GIT_TAG}" || true
  fi
  exit "${exit_code:-1}"
}

# === Setup === #
trap cleanup EXIT

# === Step 1: Build Docker image === #
log "Building Docker image: ${DOCKER_REGISTRY}/${IMAGE_NAME}:${GIT_TAG}"
docker build \
  --tag "${DOCKER_REGISTRY}/${IMAGE_NAME}:${GIT_TAG}" \
  --tag "${DOCKER_REGISTRY}/${IMAGE_NAME}:latest" \
  .

# === Step 2: Push to registry === #
log "Pushing image to registry"
docker push "${DOCKER_REGISTRY}/${IMAGE_NAME}:${GIT_TAG}"
docker push "${DOCKER_REGISTRY}/${IMAGE_NAME}:latest"

# === Step 3: Update Git tag (safe, non-force push) === #
# Record previous commit for potential rollback
PREV_COMMIT=$(git rev-parse "${GIT_TAG}" 2>/dev/null || true)

# Create and push tag only if not exists (avoids overwriting)
if [[ -z "${PREV_COMMIT}" ]]; then
  log "Creating Git tag: ${GIT_TAG}"
  git tag "${GIT_TAG}"
  git push origin "${GIT_TAG}"
else
  log "Tag ${GIT_TAG} already exists (commit: ${PREV_COMMIT}). Skipping tag update."
fi

# === Step 4: Deploy to production === #
# Save current image for rollback
PREV_DOCKER_IMAGE=$(kubectl get deployment "${K8S_DEPLOYMENT}" \
  -n "${K8S_NAMESPACE}" \
  -o jsonpath='{.spec.template.spec.containers[0].image}' 2>/dev/null || true)

log "Deploying to Kubernetes: ${K8S_DEPLOYMENT} in ${K8S_NAMESPACE}"
kubectl set image "deployment/${K8S_DEPLOYMENT}" \
  "${K8S_DEPLOYMENT}=${DOCKER_REGISTRY}/${IMAGE_NAME}:${GIT_TAG}" \
  -n "${K8S_NAMESPACE}"

# Wait for rollout (with timeout)
log "Waiting for rollout to complete..."
kubectl rollout status "deployment/${K8S_DEPLOYMENT}" \
  -n "${K8S_NAMESPACE}" \
  --timeout=300s || {
  log "Rollout failed. Initiating rollback..."
  rollback
}

log "Deployment successful!"
```

### Usage Notes:
1. **No hardcoded secrets**: All sensitive values (`DOCKER_REGISTRY`, `GIT_TAG`, etc.) come from environment variables (e.g., CI/CD secrets).
2. **No `--force` pushes**: Git tag updates use safe `git push origin tag` (only creates new tags).
3. **Rollback support**: 
   - Saves current Docker image before deployment
   - Uses `trap cleanup EXIT` to auto-rollback on failure
   - Restores previous image via `kubectl set image`
4. **Error handling**: 
   - `set -euo pipefail` ensures failures are caught
   - `||` fallbacks for non-fatal operations (e.g., `docker pull` in rollback)
5. **Logging**: Uses `log()` function (no `print()`, no `logging` module).

### Pre-deployment checks:
- Ensure `kubectl` is configured for production cluster
- Ensure `docker` is logged into the registry
- Ensure Git remote is configured for pushes
