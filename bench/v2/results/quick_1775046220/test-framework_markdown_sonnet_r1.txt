### Features

| Feature | How it works |
|---|---|
| **Assertions** | `assert_equal`, `assert_true/false`, `assert_raises`, `assert_in`, `assert_almost_equal`, etc. |
| **Fixtures** | `@fixture` decorator; test params auto-resolved by name |
| **Suite hooks** | `setup()` / `teardown()` per-test, `setup_suite()` / `teardown_suite()` once |
| **Skip** | `@skip("reason")` decorator |
| **Runner** | `run_suite(module)` for a single module |
| **Discovery** | `discover_and_run(path, pattern)` walks dirs for `test_*.py` files |
| **Output** | Color-coded `[PASS]`/`[FAIL]`/`[SKIP]` with timing and full tracebacks |

### Usage example

    assert_equal(sum(numbers), 15)
